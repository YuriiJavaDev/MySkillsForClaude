# MySkillsForClaude

Personal library of skills (`SKILL.md` files) for working with Claude on my projects. This repository is the source of truth; the skills that matter most are also saved on the account so they load automatically.

## Layout

One folder per skill under `skills/`, each with a `SKILL.md` (front matter `name` and `description`, then the body). Categories are expressed in the skill name, kept flat so tools can find every skill.

| Skill | What it is for |
|-------|----------------|
| [clean-code-principles](skills/clean-code-principles/SKILL.md) | Core engineering stance and code rules for every project |
| [myassistant-workflow](skills/myassistant-workflow/SKILL.md) | Language, style, git and verification rules for the MyAssistant app |

## Conventions

- A description says when to use the skill, not what it contains.
- One skill, one concern; keep each short.
- No secrets, tokens or personal data in this repository.
- Edit here first, then update the account copy.
